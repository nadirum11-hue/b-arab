Instal Aplikasi (PWA)

Pasang Edukasi Interaktif di HP

Gunakan tombol di bawah untuk mencoba instalasi otomatis. Jika Chrome belum mengizinkan instalasi PWA, menu ini akan memberi petunjuk alternatif.

Memeriksa dukungan instalasi...

Jika tombol instal belum tersedia

  1. Buka alamat aplikasi ini langsung di Google Chrome, bukan dari browser dalam aplikasi lain.
  2. Pastikan internet aktif dan tunggu halaman selesai dimuat.
  3. Tekan menu Chrome ⋮. Jika tersedia, pilih Instal aplikasi.
  4. Jika hanya muncul Buat pintasan, Chrome belum menawarkan instalasi PWA penuh. Periksa kembali manifest dan service worker, lalu muat ulang situs.

Catatan: tombol ini tidak dapat memaksa Chrome memasang aplikasi jika browser menolak syarat instalasi. Menu ini membantu mencoba prompt instalasi dan menunjukkan petunjuk jika prompt belum tersedia.
